# edugate

EduGate CRM - Education Consultancy & Study Abroad Management System.

## Features
- Multi-Tier Lead Management Workflow (Tier 1 Data Intake -> Tier 2 Screening -> Tier 3 Calling -> Tier 4 Counseling -> Tier 5 Admission).
- Role-based Lead Status Visibility and Transition Restrictions.
- Facebook Lead Ads Webhook integration with automatic duplicate handling.
- Automated CI/CD deployment via GitHub Actions & FTP.
